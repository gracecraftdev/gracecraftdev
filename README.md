## 🌌 Projetos em destaque

### 📚 Próximo Capítulo

**Aplicativo de gerenciamento e sorteio de livros | Projeto pessoal em desenvolvimento**

Um projeto que nasceu de uma ideia simples: organizar minhas leituras e tornar a escolha do próximo livro mais divertida.

- Cadastro, edição e organização de livros
- Listas de livros que quero ler e já li
- Sorteio da próxima leitura
- API REST desenvolvida com FastAPI
- Integração entre frontend React e backend Python

**Stack:** Python, FastAPI, React, SQLite e Git.

### 🪐 Lumi Links — Cada link é um portal!

**Hackathon Compass UOL | Projeto em equipe**

Uma plataforma de encurtamento de links que combina desenvolvimento, segurança, automação e observabilidade com uma identidade visual própria.

- Encurtamento e gerenciamento de links
- Monitoramento com Prometheus e Grafana
- Deploy em Kubernetes
- Pipelines CI/CD e GitOps
- Documentação e organização colaborativa

**Stack:** Java, Spring Boot, PostgreSQL, Docker, Kubernetes, GitHub Actions e ArgoCD.

### 🎓 EduConnect — Sistema de Gestão Educacional

Projeto acadêmico desenvolvido em Java, aplicando conceitos de Programação Orientada a Objetos.

- Gerenciamento de alunos, professores e cursos
- Organização de turmas e avaliações
- Herança, encapsulamento e polimorfismo
- Autenticação de usuários

**Stack:** Java e POO.

### 🤖 Automação com Python

Projetos voltados à automação de tarefas repetitivas, utilizando Python e PyAutoGUI para simplificar processos e aumentar a produtividade.
